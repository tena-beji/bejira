# Amazon → ヨドバシ.com リンク (Chrome 拡張機能)

Amazon.co.jp の商品ページを開くと、商品タイトルの下に「ヨドバシ.com で探す」ボタンを表示します。
ボタンを押すと、同じ商品をヨドバシ.com で検索した結果が新しいタブで開きます。

## 検索キーワードの決め方

商品ページの情報から、次の順で最初に見つかったものを使います。

1. **JAN コード**: 「登録情報」欄に JAN/EAN がある場合。最も確実です。
2. **型番**: 「型番」「メーカー型番」「モデル番号」欄、なければ商品名中の英数字の型番らしい文字列。ブランド名を前に付けます。
3. **商品名**: 上のどちらもない場合、商品名の先頭部分。

JAN や型番で検索したときは、ヒットしなかった場合に備えて「商品名で検索」リンクも並べて表示します。
カラーやサイズを切り替えて型番が変わると、リンクも自動で更新されます。

> ヨドバシ側の在庫は確認していません。リンク先はヨドバシ.com の検索結果ページです。

## インストール (開発者モード)

1. このリポジトリをダウンロード (`git clone` または ZIP をダウンロードして展開)
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、`extension` フォルダを選ぶ
5. Amazon.co.jp の商品ページ (`/dp/...` や `/gp/product/...`) を開く

コードを変更したら、`chrome://extensions` で拡張機能の再読み込みボタンを押し、Amazon のページもリロードしてください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `extension/manifest.json` | 拡張機能の設定 (Manifest V3)。Amazon の商品ページでだけ動きます |
| `extension/query.js` | ページから JAN・型番・商品名を読み取り、検索キーワードと URL を作る |
| `extension/content.js` | ボタンをページに差し込む。ページ内容の変化を監視して更新する |
| `extension/content.css` | ボタンの見た目 |

権限は Amazon の商品ページへのコンテンツスクリプトのみで、外部への通信は行いません。
